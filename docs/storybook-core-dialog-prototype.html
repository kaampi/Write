Avstängt som standard. Andra appar får läsa hela manusets prosa och synopsis samt de godkända, synliga Story Bible-fakta som ingår i ”Exportera för andra appar”. De kan inte ändra manuskriptet. Brainstorm, ogranskade fakta och dolda fakta eller entiteter delas aldrig.

Delning gäller bara det här manuskriptet. Den privata Core-kopian delas aldrig. Om du stänger av delningen försvinner det ur appens Core-lista. Material som redan importerats till ett eget projekt kan finnas kvar där.

Ett nytt manuskript får egen historik och är privat tills du väljer att dela det. Importflödet kan användas som utgångspunkt för att skapa det. Ursprungsversionen sparas som referens. Backup av hela Core hanteras separat.
